Sources and verification

Each raw capture has a sibling .source.json with actual retrieval time, request URL, final URL, HTTP status and SHA-256. comparison.json preserves the exact metadata for the principal facts. Files were captured Oct 21 UTC (Oct 20 Eastern). Raw certified PDFs include filing addresses; replay outputs retain candidate names, office, party and district only. Filed private addresses must not reach readers.

Run from the repository:

    python scripts/ba01-south-territories.py
    node --experimental-strip-types --import ./scripts/register-test-loader.mjs tests/ba01-south-territories.test.ts

The importer calls scripts/ba01-south-territory-sources.py, ba01-south-mp-samples.py and ba01-south-vi-samples.py. Every text extraction is regenerated by pdftotext from its exact hashed PDF capture and compared to the held text. A second importer replay produces identical territory package hashes.

The source parser hashes source bytes, checks explicit election dates and certified totals, and emits verified-rosters.json plus comparison.json. The MP parser compares every person to an actual specimen candidate row; parses printed vote limits; verifies all 22 race rosters against every applicable precinct; emits mp-sample-comparison.json. The VI parser compares all 70 candidate choices against the two certified tables, checks parties uniformly, preserves five explicit source name variants and emits vi-sample-comparison.json. Use the newest printed sample names uniformly when creating records. A write-in blank is not an invented candidate.
