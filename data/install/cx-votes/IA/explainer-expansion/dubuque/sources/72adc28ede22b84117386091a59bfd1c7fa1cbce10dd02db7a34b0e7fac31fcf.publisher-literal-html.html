Absentee Ballot Request Form

Starting 70 days before Election Day, the Elections Office accepts Absentee Ballot Request Forms . To receive an Absentee Ballot in the mail, the Elections Office must receive your completed Absentee Ballot Request Form by 5pm on the Monday, 15 days before Election Day.

Don't have a printer? Complete our online form and Dubuque County Elections will send you a printed Absentee Ballot Request Form in the mail.

FAQ?

Q. Will the county Elections Office send absentee ballot request forms to all voters in the county?

A. No. State law now prohibits this. If you personally request an absentee ballot request form, the Elections Office will send you one. Please visit our Absentee Voting page to learn more.

Q. What if I don’t have a four-digit Pin number?

A. When filling out an Absentee Ballot Request form this is an OR question. If you have an Iowa Driver’s License or Non-Operator ID number you should use this number as your ID number on the request form, as you are not automatically mailed a voter Pin card. However, any voter may request an Iowa Voter Identification Card.
