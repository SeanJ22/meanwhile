# acs5_2023_b01003_state.csv — source note

## Source
- **Agency:** U.S. Census Bureau, American Community Survey (ACS).
- **Dataset:** ACS 5-Year Detailed Tables, 2023 vintage — identifier `https://api.census.gov/data/id/ACSDT5Y2023`.
- **Variable:** `B01003_001E` — Total Population, estimate.
- **Geography:** every state, the District of Columbia and Puerto Rico (52 rows).
- **Request (key redacted):** `https://api.census.gov/data/2023/acs/acs5?get=NAME,B01003_001E&for=state:*&key=<CENSUS_API_KEY>`
- **Documentation:** https://www.census.gov/developer/ · terms of service https://www.census.gov/data/developers/about/terms-of-service.html
- **License:** a work of the United States federal government — public domain.

## Acquisition
- Acquired by `pnpm acs:population` (`scripts/acs-population-refresh.mts` over `lib/sources/census-acs-population`) on 2026-09-05, in the same run as the ZCTA table, with the repository's own `CENSUS_API_KEY`.
- HTTP 200; 52 data rows returned after the header row; 52 written. Pinned in `lib/reference/index.ts` and checked by `tests/reference-data.test.ts`.
- Columns: `state_fips` (two digits), `name` (the API's `NAME`, e.g. `Arizona`), `population` (an integer estimate).
- Spot values on the run: Arizona 7,268,175 · New Hampshire 1,387,834 · New Jersey 9,267,014.

## Why a separate table
- The state total is the DENOMINATOR of the readiness panel's "population in a reader-complete zip" figure. A denominator summed from the ZIPs the project happens to have researched would be a denominator the project chose; the Bureau's own state estimate is external to us, which is what RULING 159 asks of a denominator.
- Postal code → FIPS is `STATE_FIPS` in `lib/reference/acs-population.ts`.
