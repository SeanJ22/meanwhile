# acs5_2024_b01003_state.csv — source note

## Source
- **Agency:** U.S. Census Bureau, American Community Survey (ACS).
- **Dataset:** ACS 5-Year Detailed Tables, 2024 vintage — identifier `https://api.census.gov/data/id/ACSDT5Y2024`.
- **Variables:** `B01003_001E` — Total Population, estimate; `B01003_001M` — its margin of error at 90% confidence.
- **Geography:** every state, the District of Columbia and Puerto Rico (52 rows).
- **Request (key redacted):** `https://api.census.gov/data/2024/acs/acs5?get=NAME,B01003_001E,B01003_001M&for=state:*&key=<CENSUS_API_KEY>`
- **Documentation:** https://www.census.gov/developer/ · terms of service https://www.census.gov/data/developers/about/terms-of-service.html
- **License:** a work of the United States federal government — public domain.

## Why the 2024 vintage
- The newest 5-Year release the API serves, measured 2026-09-06: `/data/2024/acs/acs5` answers HTTP 200 and `/data/2025/acs/acs5` answers HTTP 404. The 2023 table (`acs5_2023_b01003_state.csv`, acquired 2026-09-05) is superseded and removed.
- The state total and the ZCTA table are acquired from the **same release in the same run**, so the numerator and the denominator of the readiness panel's population figure are never a year apart from each other.

## Acquisition
- Acquired by `pnpm acs:population` (`scripts/acs-population-refresh.mts` over `lib/sources/census-acs-population`) on 2026-09-06, in the same run as the ZCTA table, with the repository's own `CENSUS_API_KEY`.
- HTTP 200; 52 data rows returned after the header row; 52 written. Pinned in `lib/reference/index.ts` and checked by `tests/reference-data.test.ts`.
- Columns: `state_fips` (two digits), `name` (the API's `NAME`, e.g. `Arizona`), `population` (an integer estimate), `margin_of_error` (empty for every state — see below).
- Spot values on the run, independently verified by a separate live call the same day: Arizona 7,378,838 · New Hampshire 1,394,868 · New Jersey 9,343,809. The 2023 figures they replace were 7,268,175 · 1,387,834 · 9,267,014.

## Why every margin is empty here
- The API answers `B01003_001M` for a state with `-555555555` — the Bureau's jam value for "the estimate is controlled; a statistical test is not appropriate". A state total is controlled to an independent population estimate, so there is no sampling margin to publish.
- An empty cell records that the Bureau stated no margin. It is NEVER read as a margin of zero, which would claim the estimate is exact.

## Why a separate table
- The state total is the DENOMINATOR of the readiness panel's "population in a reader-complete zip" figure. A denominator summed from the ZIPs the project happens to have researched would be a denominator the project chose; the Bureau's own state estimate is external to us, which is what RULING 159 asks of a denominator.
- Postal code → FIPS is `STATE_FIPS` in `lib/reference/acs-population.ts`.

## Used by
