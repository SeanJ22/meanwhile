# State clocks for election result dates

`result_state_time_zones.json` maps the 50 states, the District of Columbia and the five inhabited territories to the IANA clock used to display election result dates. It is a static projection of the committed [national county-clock reference](national_county_time_zones.md), produced by `scripts/build-result-state-time-zones.mts`. The source reference retains NOAA/National Weather Service county clock assignments from the held 3 March 2020 correlation file, its exact source URL and SHA-256, and the county identity adjustments described in its provenance note.

The generator preserves the existing result-card clock algorithm. It first uses a state's clock when every county clock in that state agrees. Otherwise it counts counties that each have one clock and selects the most frequent clock. A frequency tie retains the reference's original first-county order. Counties with multiple clocks do not enter that tally. This state-level display choice formats result timestamps; county and government clock resolution continues to use the full county reference.

Run `node --experimental-strip-types scripts/build-result-state-time-zones.mts` to regenerate the projection from the committed county data, or add `--check` to compare its bytes without writing. `tests/result-state-time-zones.test.ts` checks all 56 entries against the previous county-based calculation, preserves local timestamp and date-only formatting, and verifies that browser result cards load this compact projection. No new source acquisition or later source-check date is implied by regeneration.
