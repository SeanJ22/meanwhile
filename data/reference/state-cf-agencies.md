# state-cf-agencies.csv — source note

## Source

- **Generated by:** `pnpm cf:agencies` (`scripts/build-state-cf-agencies.mts`). Never hand-edited.
- **Derived from:** `data/reference/fec_combined_federal_state_disclosure_directory.csv`, the FEC
  Combined Federal/State Disclosure Directory.
- **Publisher of the underlying data:** Federal Election Commission (United States).
- **Licence:** a United States government work. **Public domain — no attribution obligation and no
  terms to accept.**
- **First built:** 2026-08-24 (the state-campaign-money session, item 8).
- **What it is:** for each of the 56 jurisdictions the FEC directory covers, the office that holds
  **campaign-finance reports**, with its URL, email, phone, the directory's own records-held text, and
  a **link-verification result with the date it was checked**.

## Why this repo holds it

Each state's free sources are enumerated into the manifest **before** the first
entity of that state is touched, because *which office IS the campaign-finance authority* is per-state
knowledge that a session otherwise discovers mid-hunt, once, expensively.

The two pilot states make the point better than the rule does. **New Jersey's authority is the Election
Law Enforcement Commission; New Hampshire's is the Secretary of State.** No pattern in an office name
predicts that, and a session that assumed either would walk to the wrong door.

## What the brief expected, and what was actually there

The session brief proposed seeding this from **CFI's `stateLinks` page** and using the FEC directory as
a cross-check. Walked 2026-08-24, that is backwards in both directions:

- `http://www.cfinst.org/state/stateLinks.aspx` answers **HTTP 404**, and `https://www.cfinst.org`
  does not complete a TLS handshake at all. The 2018 fossil is not stale — it is gone.
- The FEC directory has been committed in this repo **since 2026-08-22** and covers 56 jurisdictions
  rather than 50.

So the procedure that finds this is **read the reference data already in the
tree**, and the reason it did not run is that nothing in any report contract asked a session what
`data/reference/` already held. `pnpm cf:agencies` is the change that makes it run.

## The link verification, and why a 200 is not enough

Every agency URL and every portal URL named inside the records-held text is fetched, and an entry is
counted ALIVE only when the status is 2xx **and** the body is about the jurisdiction asked for.

That control is mandatory rather than fussy: `nj.gov/nj/gov/county/` answers **HTTP 200 with a styled
"Page not found"**, which a status check alone reads as success, and
Connecticut's entry in this file is the live case — `portal.ct.gov/sec` returns 200 with a not-found
body and is recorded DEAD.

## Measured on the first build — 2026-08-24

| Figure | Count |
| --- | ---: |
| Jurisdictions in the FEC directory | 56 |
| With a campaign-finance office named | **56 of 56** |
| With none named | 0 |
| Agency URL alive | 43 of 56 |
| …of which the body is about the jurisdiction | 43 |
| Alive but the control did not match | 0 |
| Dead, refused, or unreachable | 12 |

**The twelve are named in the file with their status**, and six of them (Georgia, Michigan, New
Hampshire, New York, Ohio, Oregon) answered **HTTP 403 or 503** to a rapid sequential sweep. That is a measurement of
this sweep on this date and **not an established wall**: `sos.nh.gov` answered **HTTP 200** to a single
request earlier in the same session. Recorded as refusals with their date, to be
re-walked rather than believed.

## The Washington collision — a partial that added up

The FEC directory files its **federal** offices under the jurisdiction `WASHINGTON`, meaning Washington,
DC. **Washington State is also `WASHINGTON`.** The first build of this file therefore took the first
match and gave Washington State the **Federal Election Commission** as its campaign-finance authority,
shadowing the **Public Disclosure Commission**, which is the real one.

It reported *56 of 56 jurisdictions have a campaign-finance office named*. That figure was true, it
reconciled, and it named the wrong government for one state. The
generator now tries a STATE-specific pattern across all of a jurisdiction's offices before falling back
to the broader one, and any row that resolves to a federal office says so in its `note` column rather
than passing as a state authority.

## Refresh

CSV without calling out, for a machine with no egress.
