# Jurisdiction labels

`us-jurisdiction-labels.json` gives each of the 60 U.S. jurisdictions its USPS postal code, its name and its two-digit FIPS state code: every state-level entry in the National Center for Education Statistics Common Core of Data local-education-agency directory: the 50 states, the District of Columbia, the inhabited territories, the Bureau of Indian Education and the freely associated states (Micronesia, the Marshall Islands and Palau). The last four are NCES reporting entities, not claims about who governs anywhere. It is derived from the committed file `data/reference/nces_ccd_lea_directory_2025_26.csv` (National Center for Education Statistics, Common Core of Data), whose state columns carry the postal code, name and FIPS code together, so the three always agree.

The statewide and national people readers use it to turn a state name found on a directory page into the postal code and `US-XX` jurisdiction the rest of the data plane keys on, and to tell a state heading from a street or agency name. It lists names only: it does not say which offices a jurisdiction has, who holds them, or whether a jurisdiction is covered by any source. Rebuild it from the NCES file if that file's vintage changes, and keep the three fields from the same row.
