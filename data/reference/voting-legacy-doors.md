# voting-legacy-doors.json — source note

These are previously supported official voting routes migrated from the former voting-sites acquisition script into the generic VS-01 door format. They include Pima County map-service layers, Cochise County's current official PDF and drop-box page, Morris County lists and New Hampshire office pages. Their URLs and extraction mappings come from existing code and retained official source fixtures; they are not a national enumeration and their presence does not prove current election applicability. A map layer whose own name names an earlier election remains visible as the official linked source while a hunter blank requests a newer applicable list. Existing authoritative data must survive an unsuccessful refresh. New raw ArcGIS capture failed in this workspace; current response content is not invented. The companion test fixtures separately identify original PDF bytes and normalized browser extracts.


Native capture update (October 13, 2026): execution with the configured network capability resolved the initial workspace proxy failure. The fixture manifest now records native Montana XLSX, North Carolina files, North Dakota and vendor HTML, county pages, official rule/calendar pages, Pima app JSON and Census responses with source URLs, response hashes and robots evidence. Historical browser observations remain identified as such. Native layer queries can still be closed by their own robots response, and an older-election file stays visible with its newer-election hunter blank. Coverage counts in docs/vs-01-source-coverage.md describe committed fixtures, never unqueried production publication.

Credential handling: the Pima election HTML and two El Paso location HTML captures pass through the repository writeCapturedFixture sanitizer. Only detected credential substrings are replaced. Their manifest entries record both the raw capture hash and sanitized saved hash, alongside data/fixtures/sanitization.json; they are not described as unchanged HTTP bytes. Election text and site records remain source evidence.
