# voting-legacy-doors.json — source note

These are previously supported official voting routes migrated from the former voting-sites acquisition script into the generic VS-01 door format. They include Pima County map-service layers, Cochise County's current official PDF and drop-box page, Morris County lists and New Hampshire office pages. Their URLs and extraction mappings come from existing code and retained official source fixtures; they are not a national enumeration and their presence does not prove current election applicability. A map layer whose own name names an earlier election remains visible as the official linked source while a hunter blank requests a newer applicable list. Existing authoritative data must survive an unsuccessful refresh. New raw ArcGIS capture failed in this workspace; current response content is not invented. The companion test fixtures separately identify original PDF bytes and normalized browser extracts.
