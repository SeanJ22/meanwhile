# voting-source-doors.json — source note

The root universe comes from data/reference/fec_state_election_offices.csv, published by the Federal Election Commission at https://www.fec.gov/introduction-campaign-finance/how-to-research-public-records/state-election-offices/. Its exact links were reread with the browser on October 13, 2026. There are 54 chief-office entries covering the 50 states, DC and PR, because Kentucky and Rhode Island each have two FEC offices. FEC authority excerpts are normalized anchors from observed visible URLs, explicitly marked as such rather than claimed as original HTML bytes.

Additional doors were found by following those official pages into state files, county directories, official county lists, address-only portals and linked vendor directories. The record preserves shape, publisher, scope, coverage, election page and access observations. A root has an empty covers array because an elections homepage is a discovery source, not a polling list. Official vendor-link excerpts are likewise explicitly normalized observed destinations. November 3 is the requested election scope; individual file applicability, older titles and unresolved vendor warnings remain acquisition work. Fixture counts and inaccessible samples are documented in tests/fixtures/voting-sources/manifest.json and docs/vs-01-source-coverage.md. No identity-locked lookup was submitted, and missing source bytes or geocodes were not manufactured.


Native capture update (October 13, 2026): execution with the configured network capability resolved the initial workspace proxy failure. The fixture manifest now records native Montana XLSX, North Carolina files, North Dakota and vendor HTML, county pages, official rule/calendar pages, Pima app JSON and Census responses with source URLs, response hashes and robots evidence. Historical browser observations remain identified as such. Native layer queries can still be closed by their own robots response, and an older-election file stays visible with its newer-election hunter blank. Coverage counts in docs/vs-01-source-coverage.md describe committed fixtures, never unqueried production publication.

Their manifest entries record both the raw capture hash and sanitized saved hash, alongside data/fixtures/sanitization.json; they are not described as unchanged HTTP bytes. Election text and site records remain source evidence.
