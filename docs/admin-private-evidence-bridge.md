# Private Admin access to held original evidence

The standing runner keeps original capture bytes in its durable local evidence vault. The hosted Admin process cannot mount that filesystem. This bridge makes a second, immutable private copy only after checking the control-plane ArtifactRecord, originating Attempt and WorkItem, local sidecar, body hash, complete-capture status and permanent retention. Text captures are re-scanned under the current credential rules; binary PDF/image captures follow the existing RAW tier contract. RESTRICTED_RAW, partial, limited-retention and unsupported content types are not copied.

The ordinary runner reconciliation is disabled by default. After deployment, `WTP_ADMIN_EVIDENCE_MIRROR_ENABLED=1` on the permanent runner opts it in using its existing `NETLIFY_SITE_ID` and `NETLIFY_BLOBS_TOKEN`. It writes only to the separate site-wide `admin-evidence-private` Netlify Blobs store, with create-if-absent semantics and a readback hash check. It examines a rotating bounded slice of old and new captures after the canonical cycle outcome. A timeout or failed read leaves copy status unknown and the next cycle checks again; it never changes an acquisition or publication result. No production mirror or upload was invoked while developing this change.

Admin Work shows each saved capture and a download link for eligible RAW types. The authenticated Admin GET resolves the private key from the exact recorded WorkItem, Attempt, artifact ID and hash. It verifies the returned metadata and bytes before returning the original as an `application/octet-stream` attachment with `no-store`, `nosniff` and sandbox headers. A missing or unreadable copy stays explicit. No publisher refetch is used to satisfy this path. This route has no public blob URL or inline HTML/PDF rendering.

Sanitized derivatives from older captures are not offered as preview: the normal runner did not persist the manifest needed to prove their lineage. Adding derivative preview requires durable raw/derived linkage before treating any legacy derivative as an Admin copy. The current bridge also caps each copy at 32 MiB and does not mirror unsupported binary formats. Those captures remain held in the original vault, not falsely marked available in Admin.
