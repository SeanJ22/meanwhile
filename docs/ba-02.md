## Connections

The ordinary runner detects a changed committed state file through its HEAD blob stamp. An unchanged, successfully published file is retained on later scheduled passes. A state file newly seen by a runner is admitted without waiting for a manual request. The older SC and AS source builders now reapply voting instructions; the AS builder also reapplies official House district memberships. Rebuilding their rosters cannot restore the replaced null limits or erase the district connections.

Puerto Rico's explicit absence is a normal sourced ballot record. Its identity, promotion and reader display work without requiring a contest. Missing local-race notices are suppressed for an absence-only ballot. AS district-gap notices use official district memberships before deciding what is missing.

## Verification and handoff

`scripts/ba02-replay.mts` replays scoped production ballot envelopes, payload parts, publication history and Census geography, captured with the production `readonly` role. It publishes only into isolated memory, selects real ZIPs and calls the actual ballot page. Real React pick controls and complete route HTML are rendered. No production writes occur.

The controlled next-day replay tests both unchanged-input retention and first admission of changed input, then runs the ordinary publisher again and compares the reader payload and page. The proof is in `data/ballot/reports/ba02-replay.json`. Desktop/mobile DOM checks and screenshots come from `scripts/ba02-page-check.mts`; its report is `data/ballot/reports/ba02-pages.json`. These checks use real page code and CSS; client event hydration and live production timings are separate from the replay.

The remaining missing-count inventory lists every race's state, election, ID, title and division in `data/ballot/reports/ba02-missing-vote-counts.json`: 2,196 races across 29 other jurisdictions. SC and AS have zero missing counts.
