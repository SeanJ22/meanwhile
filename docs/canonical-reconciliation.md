# Canonical OCD reconciliation — the per-division record

Generated by `pnpm registry:build`, written up 2026-08-17 (g10, tracker **D24**).

`docs/coverage-audit-by-county.md` answers "what governments exist here". This answers a narrower question: for each division this repo holds, does the canonical vocabulary — `opencivicdata/ocd-division-ids`, `identifiers/country-us.csv` — carry a counterpart, and if not, **why not**.

The internal identifier stays authoritative and nothing here changes that. Adopting the canonical shape wholesale would make Rockaway Township unrepresentable, because the canonical list does not carry New Jersey's townships. The canonical id rides alongside with a confidence, and **anything that is not an identifier match is not a join**.

## How a match is made, in order

| Verdict | Basis | Count |
|---|---|---|
| `exact` | The two identifiers are the same string. | 528 |
| `geoid` | **Census GEOID**, which both sides publish — the canonical CSV's `census_geoid` column against the GEOID on every boundary feature. An identifier match, not a name match. | 140 |
| `census_name` | The Census's own NAME field parsed into the components the canonical slug is built from, then required to be present in the canonical set. New Hampshire's House districts only: the canonical list slugs them `sldl:merrimack_8` where this repo carries the Census SLDLST code `sldl:608`, and it publishes no `census_geoid` for any legislative layer. No similarity and no nearest match — a constructed id that is not present is a miss. | 43 |
| `none` | Nothing corresponds. Every one carries a stated reason below. | 229 |
| | **total** | **940** |

**Nothing is matched by slug similarity any more.** The reconciliation used to settle 64 divisions on "same terminal segment, same state", which is a name comparison; every one of them now matches on GEOID instead. `high` and `low` remain in the type as review states and are empty, guarded in `tests/canonical-reconciliation.test.ts`.

## The gap, per division

229 of 940 divisions have no canonical counterpart. Each reason is read off a Census field this repo already carries — never inferred from a name.

| Reason | Count | What it means |
|---|---|---|
| `NOT_A_GOVERNMENT` | 112 | Census FUNCSTAT **S** — a statistical entity. A census designated place is an area the Bureau draws so it can publish numbers for a populated place that has no government; nobody is elected to it. Correctly absent from a list of governments, and its absence is not a gap. School-district pseudo-entities (GEOID ending 99997/99998/99999, "school district not defined") are here too — the Bureau draws them so the school layer tiles the state completely. |
| `GOVERNMENT_NOT_LISTED` | 85 | An **active government** — FUNCSTAT A, B, C or G, or a school district with an elected board — that the canonical list does not enumerate. **This is the real gap, and it is a gap in the canonical list rather than here.** The Census publishes a boundary for each of these and this repo holds it; opencivicdata does not carry an identifier. Nothing is minted for them: the internal key stays authoritative, exactly as `lib/registry/types.ts` describes, and `canonicalOcdId` stays null rather than becoming a plausible-looking invention. |
| `FICTITIOUS` | 32 | Census FUNCSTAT **F** — an entity created only to fill the Bureau's geographic hierarchy, so that every part of a state belongs to some county subdivision. Not a government. Correctly absent. |

So of the 229 unmatched, 144 are correctly absent because they are not governments, and 85 are governments the canonical list omits.

```bash

```
