# CS-01 reader casing

READY covers the display change with the state exceptions permitted in the task follow-up. The full browser scan exits 1 for thirty missing-board journeys in fifteen states; those required paths are not reported as passing.

Reader text uses one word-level formatter in `lib/text/reader-names.ts`. Names, titles, addresses and sentences share the acronym list and name spellings. Reader components format strings when they display them; raw source facts, quotations, keys and link destinations remain unchanged. Long sentences and Sources quotes inherit the people, places and bodies held in their reader view.

The upstream connection is PB-01's canonical roster projection (`lib/facts/roster-read.ts` → place/state coverage and `readerRoster`). CS-01 formats that projection at reader components. The downstream connection is the shared person/body/meeting cards and BL-01's ballot display. Ballot changes only wrap displayed titles and measure wording and case text labels; contest selection and drawing are untouched.
