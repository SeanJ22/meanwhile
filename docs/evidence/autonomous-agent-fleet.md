## Implemented path and authority boundaries

The existing WorkItem → RouteTask → Attempt → lease → completion chain now carries Scout, Acquirer/Hunter, Parser, Validator, Detective, Adversarial Auditor, and Engineering work. Scout continues to discover genuinely novel routes through the existing bounded research tools. Acquirer retrieves an observed, permission-grounded route or reuses the exact immutable, current held artifact. A worker result is committed through the existing append-only worker-result family with the exact closed Attempt and completed RouteTask snapshots; recovery applies that recorded completion rather than rerunning successful work.

`workers/coordinator.ts` selects the next action from the owed WorkItem and canonical results. `workers/standing-runtime.ts` configures the existing Scout and role tools. `scripts/freshness-shadow.mts` integrates the coordinator with the existing standing cycle. Legacy event contracts remain supported, and the legacy loop's admission and drain filter cannot bypass generalized identity work. Retry and restart controls distinguish live leases, expired leases, successful committed results, diagnostic replay, and unresolved research.

Generalized contracts describe canonical subject, jurisdiction, record identity, publisher source scope, method version and a bounded extraction shape. JSON records, HTML tables, delimited text, and XML records preserve exact source spans. Unsupported shapes fail explicitly. Independent validation separates faithful extraction from external civic verification. The auditor constructs its subject/route/authority inventory before reading the candidate, including relevant additional publishers joined to the same subject, and excludes unrelated records even when they share a host. Missing required external authority remains INCONCLUSIVE.

Detective compares explicit alternatives against held authoritative evidence; model hypotheses remain unverified. An ambiguous join or unknown external denominator stays unresolved. Engineering accepts validated source extraction plus a proven learned method, emits an implementation/test candidate, and executes its reproducibility proof in restricted scratch processes. It cannot install its candidate, merge code, change governance, edit the UI, deploy, or mutate reader-serving data.
