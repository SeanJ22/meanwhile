# EX-03: ballot explainers for every state

A resident opening a ZIP ballot gets the checked statewide explainers already held for that state, including the summary, YES meaning, NO meaning and Sources links. The standing translator recognizes the workers' workspace API limit, releases paid capacity and records the provider's plain-language reason in the source outcome Admin reads. Existing spending settings stay in force.

Built on `stream/ex-03`, cut from `origin/river` at `78f82a232dd1d0545a46835e7716032ff3807425`. `lib/civic-data/runner.ts` is unchanged. RN-01 owns fair admission among states.

Inputs: **BA-01** publishes state ballots with exact measure identities and full-text links; **EX-02** finds missing sources; **RN-01** admits each state's standing translation task. EX-03 uses those same ballots, source captures, paid guards, attempts and publication contracts.

## Causes and repairs

- The shared provider classifier did not recognize Anthropic's HTTP 400 workspace usage-limit response. It now treats it as a hard refusal and extracts the provider's sentence, including its access-restoration date, from the HTTP JSON diagnostic. The routine gate immediately exposes that closure, reports zero paid capacity, and checks it again before queued requests reach the provider. A concurrent successful request cannot erase the closure. The script uses that reason for its durable held outcome, advancing the existing retry clock.
- Captures ignored the ballot's `measureTextUrl`. Capture, translation admission and reader attachment now use that exact verified link. A bill can use its legislative title while the ballot uses an amendment number.
- Alaska's successful production search capture was the Lieutenant Governor's official hearing notice. The old matcher compared the full combined ballot title with the page's shorter designation and rejected both measures. Discovery, writer admission and reader attachment now share the designation/act-title matcher, preserving number boundaries and the supplied official designation. The read-only replay admits both real AK measures to the writer from saved official page bytes.
- Alabama recovered during this investigation: production published all four checked explainers at 06:49 UTC on October 23. Its live map-point ballot shows them, but ZIP 35203 does not. The ZIP's production geography names local divisions without the state division. The ballot loader includes statewide contests while the translation read previously requested only local scopes. It now reads the containing state's explainers as well, through the existing parallel read.
- A successful state receipt previously required a statewide translation projection even when all measures were local. It now checks every current measure in its exact division, confirms those real projections and returns a receipt for one of them. The supervisor validates that local candidate within the scheduled state. Another state, a missing local projection or a missing measure cannot pass. No statewide explainer is fabricated.

Replaced matching and circuit-merge logic was removed from its former locations.
