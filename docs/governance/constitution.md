**The canonical store is `docs/governance/ledger.jsonl`. Everything else — `CLAUDE.md`'s policy index, every policy, the autonomous-system constitution, `rulings.md`, `history.md`, `current-decisions.md` — is a view of it, regenerated by `pnpm governance:compile` and checked by `pnpm governance:check`. A generated artifact is never hand-edited; the generator is fixed and the artifact regenerated and diffed, and a generator whose digest moved fails the build until its output is regenerated.**

- **Authority precedence, one model:** (1) explicit current author directive; (2) `CLAUDE.md`; (3) the delegated current policy; (4) active non-law author decisions; (5) the session brief; (6) operational state and measurements; (7) history. History explains; history never overrides. A brief that conflicts with current law does not silently win unless it is an explicit author amendment — the conflict is represented, not resolved by whichever document was read last.
- **Binding authority requires author provenance.** Only `author_explicit` or `author_confirmed` may create law or decision state. A session's reading is recorded as a reading; a measurement is recorded as a fact; neither becomes the rule by being written confidently.
- **Amendment.** A ruling changes only by a later-dated ruling that names the number it supersedes and states what changed and what survives — structured relations, never a boolean. Rulings are never edited in place, never silently dropped; a superseded ruling stays in the record marked superseded. Numbers are global, immutable, never reused.
- **A governance change is atomic.** The ledger event, the operative policy, the regenerated views, the regenerated startup context and a passing `governance:check` land together or the change has not happened.
- **A session opens on task-relevant current authority** (`pnpm governance:open --task <domain>`), never on the full history. Anything a session must read at the start lives in the repository; a file the author places in the repo is registered into git unread, and the fence on its content stands. No generated file has a size limit.
- **Status is generated, never asserted.** A status claim names the gate or test that fails when it stops being true, with timestamp and SHA. One canonical verdict function per decision class — a model switch, for instance, is SWITCH only if every required question is measured and holds, and no second function may emit a verdict.
- **More principles will not fix behaviour.** What changes behaviour is a required output that cannot be produced by walking a list, and an instrument that refuses. A rule without an instrument is guidance.
