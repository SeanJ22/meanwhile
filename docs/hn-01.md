## What changed

The free meetings-discovery route now reads real government pages and official directories. The replaced `ROUTINE_READ` route and the old unexecutable discovery descriptor are deleted. The parent disposes descriptors with no HTTP request without starting a route worker. `ROUTINE_READ` remains in the shared executor and registry because current River's DG-owned `ask-gaps` provider still produces it.

The source worker runs in the actual route-worker entrypoint. The background provider reads CP's seekable source index directly, avoiding the registration script's broad JSON tracing in web bundles. Captured verification evidence is retained outside the deployable repository tree. The source worker uses CP's place planner, scoped held national and native facts, and saved evidence from any job before reading more pages. A native government also resolves its canonical place before looking up held rosters. It follows published links, saves actual source documents and observations, reports each finding immediately, and retains the source frontier in the existing field manual. It holds one government and its place scope in one state. Platform links are passed to the existing discovery path; platform acquisition remains MP-01's work. Failed sources and unsupported fields remain open work.

The current held catalog provides 111,858 background governments in 56 states, DC and territories, with 57,354 recorded sites and official directory routes for the remaining 54,504. Regenerating River's projected references exposed the existing CISA/NCES listings; no focus places were added or selected. Free work retains the existing scheduler's lower priority. Hunt packets still come from Admin's existing owner-order path.

Findings retain the reporting job and the original source job, URL, capture time and content hash. Identical bytes acquired at different URLs or times retain their observations without changing immutable content. Box publication handles new bodies and independently verified fields, including portraits, when dependent body or seat findings arrive in later batches. A contact or portrait attachment does not refresh a seat's evidence. Actual reader SQL exposes the new body type and portrait. Audit findings flag seats for Admin rather than automatically pulling them, as §2 requires.
