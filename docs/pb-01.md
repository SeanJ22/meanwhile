# PB-01 — board names without empty boards

**The nationwide follow-up supersedes this two-place readiness assessment. PB-01 is not READY while the failures in [the nationwide report](pb-01-national.md) remain open.**

Residents can see verified Legistar boards and their members as names publish. The production-data replay shows Dane's `#governing` board with 37 members and **Henry Fries once**. Milwaukee shows **171 boards, all with members**. The built page displays those members and restores the complete official source link in Sources.

The upstream step is the standing **Legistar members refresh** (`legistar-members:<tenant>`): registered doors feed bodies, persons and current office records into the fact publisher every 12 hours. PB-01 feeds **PB-03's place assembly**, then `stateCoverage`, `/api/meetings`, the ZIP bootstrap and the body card. `lib/facts/box-publication.ts` and `lib/reader/place.ts` are untouched.

## Change and ownership

The publisher selects body names from current seats or a Legistar board type, including boards, commissions, committees, councils, authorities and legislative bodies. Dates use the same local-day rule as member rosters. Each refresh supersedes this publisher's ineligible official body-name facts, preserves source evidence and person names, and invalidates the existing reader cache. Old caches force a full read selecting `BodyTypeName`; unchanged row versions cannot retain the old selection forever.

There is a real distinction in the source: many seatless Milwaukee bodies have type **Board or Commission**. Their verified names satisfy the requested type exception. The reader excludes seatless Legistar additions, so these names do not create empty reader boards. The full three-tenant production copy superseded **35 ineligible names** (Milwaukee city 2, county 33), including Law Library, Medical Examiner and Parks Department. That is a measured scoped retirement, not a claim that all 651 nationwide seatless names were deleted in production. The same cleanup runs for every tenant on its scheduled refresh.

A real Milwaukee source replay also found `VACANT` and `VACANCY` entries aborting refresh as invalid person names. These placeholders no longer become people or abort publication of valid members.

Long links, repeated source receipts and repeated object fields travel once in each answer. The worker, early HTML parser and ordinary client reads restore the exact values before the reader uses them. The previous repeated response representation is replaced. Source quotes and stored spelling remain exact.

CS-01 owns all further casing work. The already-built roster-reader call to the existing name formatter is left in this branch as Sean instructed; no separate formatter was added.
