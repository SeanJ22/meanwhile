The place query runs in `lib/reader/place-builder.ts`. The worker saves ready answers and their existing body, member, meeting and source identities in `place_page`, increments the version, then clears that place's `reader-place` cache tag. Writers queue affected places through the shared cache invalidation path. The ordinary ZIP request reads one composed ready page; other map and body selections combine saved pages through the common decoder. The previous per-visit query and reader-database `cp_work_items` read are removed. The command center reads rebuild movements from the existing state/hour counters.

The queue records which source generation is already saved. A failed cache purge retries only that purge: it does not reread source rows, increment the page version or count another rebuild. A later source change still builds a new generation. Initial preparation runs after the application build and before Netlify publishes it, drains unbuilt generations and checks for missing pages. It needs no build-host cache credential; later-version purges remain queued for the deployed worker. Compatibility hooks retain arrivals from the preceding deployment until the new writers are serving. Owner fact corrections and their rebuild requests commit in the same transaction.

ZIP pages also carry their precomputed territory selection in private compressed metadata. The canonical ZIP request uses that selection from its single ready-page read, avoiding a separate territory-geometry load. The selection includes both inside bodies and the known territory-body set, so an outside body cannot fall back to its county/city filing. Public response fields and identities are unchanged. Legacy pages without metadata retain the geometry fallback; custom coordinates retain their point lookup. Synthetic tests compare the complete coverage, member, official and meeting responses for inside, outside, overlapping and empty selections, and prove one ready SELECT with zero geometry loads or fetches. The ZIP source context remains `{formatVersion:1}`. No new remote geometry or Neon probe ran for this change.
