## Causes and implementation

The runner could start nested work without a separate reservation. Admission also used recent small runs to reduce a script's reservation, and some prefixed commands were classified by their wrapper instead of their executable. Every child now acquires shared admission before spawn, keeps its executable's declared floor, and raises that floor from observed high-water memory. Adaptive observations belong to the exact loaded release. Nested reservations own their process memory separately, so their parent does not reserve the same growth twice. Zombie processes no longer retain reservations.

Source jobs loaded national source records and national predecessor projections before selecting a state. The replacements stream acquisition to disk, publish state or native-subject partitions, and slice legacy publications inside PostgreSQL before transfer. Routine upkeep, audit history, mirror scheduling, task handouts and file-backed repositories use bounded pages or disk indexes. The shared copy host streams uploads and downloads instead of buffering complete copies in the supervisor.

Hunter budget memberships and the spend-window counter now use disk-backed snapshots, bounded pages and exact subject lookups. Research and freshness scheduling now use state or subject pages and disk indexes; complete parent measurements still prevent a final capacity claim. The authorized state FEC implementation preserves the production source identities and amounts as verified below. Authentic worker replay and the complete frozen before/after workload remain open.

The shared method catalog now stays on disk. Workers receive the version and their own place's route floor; route histories, claims and country exclusion lists do not cross worker RPC. Raw route-shape validation is projected in the existing paged SQL query, preserving malformed-record and duplicate/version behavior without per-route queries. Publication's former country-wide official-link map is deleted: a nonofficial host looks up only that exact host and retains its three newest linking artifacts. Cross-state reuse of legitimate links is preserved.

Admission retains provisional process identities while a new child has not yet bound its reservation, and retains proved bindings until in-flight OS samples finish. A delayed sample cannot permanently assign a released managed child's peak to its parent. Genuine unmanaged browser peaks and every declared floor remain reserved; the 768 MiB margin is unchanged. Focused ownership checks cover both races and monotone genuine peaks.

Shared browser requests use one browser with separate job contexts; method snapshots and copy-host services are also shared. Host admission accounts for the runner's cgroup and treats only clean, reclaimable inactive file cache as available; shared-memory, dirty and pinned pages remain charged. Five PDF readers now destroy each document transport and worker after extraction, including failure paths. Nested repository observers preserve the original receiver and stable proxy identity, so native method snapshot tokens survive route-floor reads and shutdown. These changes address retained source/document memory and shared-tool duplication; they do not lower the required margin.
