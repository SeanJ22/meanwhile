# RN-01: fair planning and routine source turns

Residents outside the first few states must get their polling places, calendars and other source updates through the same automatic runner. This change moves §0's current coverage, prompt delivery and visible blockers tests.

Branch: `stream/rn-01`, cut from `origin/river` at `78f82a232dd1d0545a46835e7716032ff3807425`. Built and tested; River owns integration, shipping and the live checks below.

## Repairs

- The round reads the latest completed `FRESHNESS_CYCLE` time from each of the 57 `owner-digest:<state>` keys. Never-finished states precede the oldest finished states. Finished states move to the back durably, so a release restart offers the unfinished tail first.
- Each state's blocking walks share two minutes. Their transport timeouts use the remaining allowance; the existing walk frontier and source evidence survive yielding. Leads and method spreading share that allowance in parallel with the walks. Metadata reads and settlement remain additional work; two minutes is a walk allowance, not a claim that a complete round has already been measured in production.
- Overdue meetings and genuinely untried first reads precede steady work. Failed baseline retries join last-attempt ordering rather than retaining first-read priority indefinitely. Never-run tasks lead equal no-deadline work. This ordering runs after the ballot, place and serial-lane tie preferences, so those preferences cannot move overdue calendars behind them.
- Hunt admission reads only effective runner pause/resume controls and states with current source orders. It no longer loads planning history to answer that question or probes every state's empty order list. The HTTP request deadline is installed before startup database work.
- Source admission starts before fact maintenance. Maintenance takes one state per pass, rotates its state cursor, and resumes partial imports at completed records of the same input version. A partial import never stamps the whole input complete. Page refresh, hourly probes and the one-time federal split have deadlines; fact database connections and statements have finite transport bounds.
- Every skip and defer goes through one recorder into the existing control-plane digest store. Small state batches retain the task, source, scope, time, reason and technical detail. Admin's existing workers feed and waiting list read them; a failed read is shown as unknown. These records do not count as source attempts and do not discharge work.

The previous static no-deadline fallback, post-sort priority pipeline, broad hunt-control read and unbounded country import loop were replaced. There is no fallback switch. Sean's settings and spending limits are unchanged. The worker memory admission system and its 0.75 GiB reserve are unchanged; this adds no worker concurrency.
