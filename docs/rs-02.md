## Reproduce

Use the existing private read-only environment without printing it, the unchanged boundary setting from `netlify.toml`, and the managed proxy environment. Run without competing builds/tests and use distinct output paths.

```sh
NODE_USE_ENV_PROXY=1 node --env-file=/tmp/rs02-production.env \
  --experimental-strip-types --import ./scripts/register-test-loader.mjs \
  scripts/rs-02-check.mts --live-before=.scratch/rs02/public-before.json \
  --out=.scratch/rs02/current-reader-all50.json

NODE_USE_ENV_PROXY=1 PLAYWRIGHT_BROWSERS_PATH=/tmp/rs02-playwright \
  node --env-file=/tmp/rs02-production.env --experimental-strip-types \
  scripts/rs-02-browser-check.mjs --follow-up=1 \
  --out=.scratch/rs02/current-browser
```
