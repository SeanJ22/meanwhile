Branch: `stream/ui-03`, cut from River `a24a073807bc8991a2cd579eb1a9065d07f57939` (main at assignment: `9a159f69f`). Step: UI-03.

Readers get readable contact controls, consistent ballot actions, one address-dependent-contest label, and an uncluttered meetings list. This moves §0's test that a resident finds the site correct, easy and a pleasure to use.

## Changes

- The shared state-office cards use the existing contact control, with 14px labels, wrapping and targets at least 44px tall. Their two callers are the ballot and Who governs here. The same contact styles serve candidate and official cards.
- Ballot actions share one shape. The voting entry button is styled through the common action rule without editing VS-01's component. One line beside Narrow this to where you live explains ◆ marks. Candidate contests and measures use the mark. Both long ZIP explanations and their duplicate address form were deleted.
- The shared ReaderCard renders the ZIP as a place label. Empty meeting lists use readable text and have no sort/group controls. Populated lists retain working sort/group controls; both actions were exercised in the browser.
- Ballot filing pointers, shared source footnotes, source labels on official analysis, timeline citations and absence-record citations were removed from the face. Provenance and source scope live in the relevant card's Sources. Missing measure wording and analysis text contribute to the existing card gap footer. Replaced filing-note and incumbency-note components and tests that required their old copy were deleted.
- Privacy copy was removed from all AddressPrompt states and from Feedback. What this site collects now describes usage/Ask records, hashed browser keys, reactions and picks, feedback's optional reply email, browser storage, both address lookups, external recipients and retention. The blanket claim that everything is anonymous was deleted.
- Address scope now uses persistent browser storage, matching the instruction to remember it until Forget this address. The shared location hook reads the same store. Forget clears it and widens the ballot. The field for a house number is still cleared in the existing request's finally block.

No page data-loading function, Ask component, sidebar, map-entry file, voting-panel file, or map-reset-btn rule was changed.
