## Acquisition changes

Physical location records can retain multiple services and precinct assignments, each with its source; schedules retain their published dates and hours. Source replacement preserves independently sourced services and keeps older source dates after a failed extraction. Official/newer source values take precedence and conflicting values are logged. Publisher coordinates and unambiguous held coordinates are reused.

Exact response bytes are compressed and held with the acquisition in the existing immutable payload parts, outside the reader payload. URL plus content hash preserves different POST pagination responses from the same URL. Extracted sites, schedules and assignments retain their document hash. Configured location constants must occur in the captured document. Official GeoJSON/ArcGIS precinct acquisition checks pagination, polygon coordinates and county identifiers; missing boundaries/assignments join existing standing work. The obsolete reader-address forwarding path has been deleted.

Nationwide acquisition and verification have **not** been completed. The full state/county/town/precinct organization, cross-source reconciliation and large-state read costs/performance still need verification with acquired data. The reader currently reads one canonical voting projection for each intersected state; this is not yet a demonstrated county-only database read for a large state.
